## ✅ P0 Features Implemented

### 1. Doctor APIs (CRUD + Photo Storage)

**Model Changes (`models/Doctor.js`):**
- Added `type` field: required, enum: ['TCM', 'Physio', 'Western']
- Added `enumTranslate` for Chinese labels (中醫師，物理治療師，西醫)
- Added index: `{ type: 1, isActive: 1 }`

**Route Changes (`routes/admin.js`):**
- `GET /api/admin/doctors` - Added `?type=` filter support
- `POST /api/admin/doctors` - Now requires `type`, supports `photo` file upload
- `PUT /api/admin/doctors/:id` - Supports photo upload

**Photo Upload (`middleware/upload.js`):**
- New multer middleware
- Storage: `/uploads/avatars/doctor-{timestamp}-{random}.{ext}`
- Limits: 5MB, images only (jpeg, jpg, png, gif, webp)
- Server serves static files from `/uploads`

### 2. Service APIs (CRUD + Duration + Pricing)

**Status:** Already complete from Sprint 2
- `duration`: Number, optional, default 30, min 5
- `price`: Number, optional, default 0

### 3. Schedule APIs (Doctor Availability)

**Model Changes (`models/Schedule.js`):**
- Added `serviceId` field: optional, references Service
- Fixed index: `{ doctorId: 1, date: 1 }` (was incorrectly `doctor`)
- Added index: `{ clinicId: 1, date: 1 }`

### 4. Available Slots Algorithm

**Enhanced Endpoint:** `GET /api/admin/schedules/available-slots`

**New Features:**
- Accepts `serviceId` query parameter
- Uses service duration for slot sizing (default: 30 min)
- Considers existing appointments (pending/confirmed) as booked
- Returns slots with proper duration

**Algorithm:**
```javascript
generateTimeSlots(openTime, closeTime, existingSchedules, existingAppointments, serviceDuration)
```
