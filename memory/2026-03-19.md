## Sprint 1 Backend Development

### Database Schema (MongoDB Collections)

**7 Collections Created:**

1. **clinics** (診所)
   - `name`: String
   - `address`: String
   - `phone`: String
   - `isActive`: Boolean

2. **doctors** (醫生)
   - `name`: String
   - `nameEn`: String
   - `type`: 'TCM' | 'Physio' | 'Bone'
   - `bio`: String
   - `avatar`: String
   - `isActive`: Boolean

3. **services** (服務)
   - `name`: String
   - `nameEn`: String
   - `duration`: 15 | 45 | 60 (minutes)
   - `isActive`: Boolean

4. **doctor_services** (醫生 - 服務關聯)
   - `doctorId`: ObjectId
   - `serviceId`: ObjectId

5. **schedules** (排班)
   - `doctorId`: ObjectId
   - `date`: String (YYYY-MM-DD)
   - `startTime`: String (HH:mm)
   - `endTime`: String (HH:mm)
   - `isOverride`: Boolean

6. **appointments** (預約)
   - `clinicId`: ObjectId
   - `doctorId`: ObjectId
   - `serviceId`: ObjectId
   - `date`: String (YYYY-MM-DD)
   - `time`: String (HH:mm)
   - `status`: 'pending' | 'confirmed' | 'cancelled'
   - `patientName`: String
   - `patientPhone`: String
   - `notes`: String
   - `duration`: Number

7. **system_config** (系統配置)
   - `key`: String
   - `value`: Any
   - Default: `bookingWindowDays: 30`

### API Endpoints

**Public APIs:**
- `GET /api/clinics` - List all clinics
- `GET /api/doctors?clinicId=&type=` - List doctors with filters
- `GET /api/services?doctorId=` - List services (optionally filtered by doctor)
- `GET /api/slots?doctorId=&date=&serviceId=` - Get available time slots
- `POST /api/appointments` - Create new appointment
- `GET /api/config` - Get system configuration

**Admin APIs (require X-Admin-Token header):**
- `GET/POST/PUT/DELETE /api/admin/doctors` - Doctor CRUD
- `GET/POST/PUT/DELETE /api/admin/services` - Service CRUD
- `GET/POST/PUT/DELETE /api/admin/schedules` - Schedule CRUD
- `GET/PUT/DELETE /api/admin/appointments/:id` - Appointment management
- `GET/PUT /api/admin/config` - System config

- All models in `/models/` folder with consistent CRUD interface
- Routes split into `/routes/public.js` and `/routes/admin.js`
- Run `npm run seed` to populate database
