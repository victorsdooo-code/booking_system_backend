# Create Backend GitHub Repo

## Steps

1. **Go to:** https://github.com/new

2. **Repo name:** `booking_system_backend`

3. **Visibility:** Public repo

4. **⚠️ IMPORTANT:** DO NOT initialize with README, .gitignore, or license

5. **Click "Create repository"**

6. **Follow the push commands shown on the next page:**

```bash
# If you see these commands, run them in the backend directory:
git remote add origin https://github.com/victorsdooo-code/booking_system_backend.git
git branch -M main
git push -u origin main
```

## After Pushing

Once the code is pushed successfully:

1. Verify all files are visible on GitHub
2. Check that `package.json` and `server.js` are present
3. Proceed to configure Render deployment
